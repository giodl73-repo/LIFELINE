# CalFresh postimplementation source status — August 1, 2026

The source spine was rechecked 61 days after California's June 1 implementation
start. The check found implementation guidance and monitoring channels, but no
complete candidate-coded recertification cohort.

| Official surface | Current finding | Candidate use |
|---|---|---|
| CDSS ABAWD implementation page | Rules began June 1; county waivers are listed through October 31, 2026 | mechanism and delivery perimeter only |
| CDSS STAT 47 | Page labels July–September 2024 and ongoing data updated June 18, 2026; files are temporarily removed during a de-identification update | no available replayable postimplementation outcome rows |
| CDSS All Partner H.R. 1 Advisory | Implementation meeting materials and future cadence | implementation context, not candidate-coded access, rights, capacity, or cost outcomes |

Elapsed time does not substitute for evidence. At 61 days, no full
recertification cycle can have elapsed since the implementation start; source
availability and candidate coding would remain separate requirements even
after more time passes. The existing executable observation check therefore
remains unchanged at zero postimplementation operations rows, zero
candidate-coded rows, and zero complete cycles.

The candidate stays held. Reopen when an official aggregate series supports a
candidate-coded cohort spanning exposure, exemptions and waivers, service,
correction, notice and appeal, adequacy, distribution, county capacity, and
actual implementation cost through a complete recertification cycle.
